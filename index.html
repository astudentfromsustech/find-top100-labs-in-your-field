Method

The roster comes from OpenAlex: every work matching the field query (2019–2026) is walked, and each paper's first and last author is counted — the PI signal. Middle authorship is ignored so a 900-author consortium paper cannot mint hundreds of phantom labs.

Seven indicators, each log-transformed, z-scored across the ranked labs and rescaled to 0–100, then weighted (adapted from U.S. News Best Global Universities and QS, which weight citation excellence and reputation similarly): works in the top 1 % and top 10 % of field-normalized citations (19 % each), first/last-author output in the field (19 %), citations received 2021–26 (13 %), h-index and 2-year mean citedness (12 % each), works 2021–26 (6 %). GitHub stars are shown but carry 0 % by default — only some labs have a curated repo list, so scoring them would rank "we catalogued this lab's tools" as "this lab's tools are used". Move any slider on a ranking page to see how much the order actually depends on the weights.

What this is not

  • Not a judgement of scientific quality. It measures publication and citation footprint in one field's literature, which is a proxy at best.
  • Consortium papers inflate every co-author; large-consortium fields therefore reward participation.
  • An author is a proxy for a lab. OpenAlex sometimes splits one person across records or merges two people into one; obvious cases are pinned by hand, the rest are not.
  • The field query defines the field: a different query gives a different roster. The corpus size behind each ranking is stated on its card above.
